# 工作流

## 盘点与样章

阅读 Skill 和模块指引，确认输入只读。执行 inventory，比较译稿首尾与原版页，记录物理页码、字体角色、正文范围、地图及译者附加导航行号。先只配置一章，不需要提前为整本书猜测参数。

配置 book/chapters/roles/art/maps/caption_glossary。题名、署名、章节背景标题、地图标签等新增文字必须有出处；原创示例例外且已明确标为占位。用字体工具准备静态实例和本书文楷子集。

提取英文角色、图片，检查角色分布；制作素材联系表，排除底纹误判。运行规范化和内容 QA，抽查统计块、表格及所有去重/排除。先编译样章，实际看图确认章首跨页、译者显示、首段、版心和字体。

## 全书

扩充章节配置和词表后执行 build.py --prep，再完整 build.py。默认以最多 4 个浏览器任务并行编译章节；--jobs N 调整，--serial 或 --jobs 1 串行。准备步骤仍按顺序执行。前置区先确定基准，章节并行分页后自动校正变化的起始页；独立工作目录与自动端口避免任务互相覆盖，合并和 PyMuPDF 操作在主线程按章序执行。检查 state.json 的前置区页数、各章起始页、页数和 toc，直到连续完整构建稳定。

执行内容、溢出、结构和美术 QA。每条未命中都需分类解释，不通过降低门槛隐藏丢字。逐张看全书联系表；可疑页单页放大，重点看章首页之后、地图标签、统计块和浮动插图。

## 报告与交付

- build_report.md：输入版本（不含私密路径）、依赖/浏览器版本、实际命令、页数构成、产物。
- qa_report.md：覆盖率、未命中、溢出、结构、图注、实际目检范围和剩余问题。
- proofreading_report.md：疑似笔误、译名差异、新增文字来源、格式规范化、drop/去重复核。
- art_mapping.md：脚本生成，人工确认启发式成书页匹配。

所有数字来自最后一次构建。不在未查看图片时声称视觉验收，不把占位示例通过当作某本真实书籍通过。输入、译文、图片、字体、PDF 与包含这些内容的报告只保存在本地被忽略的模块目录。
