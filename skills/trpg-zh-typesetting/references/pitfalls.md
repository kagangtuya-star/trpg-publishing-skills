# 关键陷阱

- 统计块分组：陌生行不能直接丢弃。孤儿统计行作为普通段落输出；真正的 Markdown 标题结束统计块；重复标题去重记日志。用内容覆盖率找静默丢行。
- 表格：破折号替换不能作用于表格分隔行；PDF 文本顺序与表格视觉顺序可能不同，逐单元格核对。
- 翻译对齐：数字/区域编号/拉丁词锚点和插值不是语义理解。角色转移错位时修配置或局部规则，不能重写译文“配合”输出。
- 空白页：命名页切换会强制分页；零高度 running/orig 标记不能独占分页边界。查看低文字量页，尤其是两页章首后的第一页。
- 章首奇偶：文档第一页是右页，用占位页调整；删除占位页后仍需检查合并成书的物理页。
- 字体：静态 TrueType、每字重独立 family、中文回退、文楷子集；不能凭 CSS 判断实际嵌入字体合格。
- 图注：以原版为身份依据，中文取本章译稿；同页多图的“最近”算法需人工复核。
- 地图：英文描边和光晕可能是矢量路径。redaction 保留图像但去除覆盖的线稿，可能损伤图面；保留原始输入，检查裁切结果。
- 素材：底纹、牌匾和缩略图可能被误判为插图，配置 textures/excluded_pages 或 use=false。
- 压缩：构建前降采样副本，不对成书使用 rewrite_images，避免破坏 PDF Pattern 资源。
- 书签：部分横幅限制在 ≥18 pt 的行中匹配，避免匹配章内目录或正文引用；很长的章节仍可能超出有限搜索窗口。
- 目录：前置目录长度变化会改变章节页码，需要完整重建到稳定。
- 浏览器：使用 CLI --executable-browser，不在 Vivliostyle 配置内写 browser 对象；路径用环境变量，版本看真实锁文件。
